# StarTracker Sample Data

This directory provides synthetic and privacy-preserving mock CCTV assets for demonstration and testing.

## Directory Structure
- `images/`: Bounding box crops, license plate crops, and CCTV frame snapshots.
- `videos/`: Short video clips for testing `process_video.py`.

## Privacy Notice
In compliance with Smart India Hackathon ethics guidelines:
- All person data contains only clothing color attributes (upper-body torso).
- No facial biometric data, identity records, or private personal data is stored or processed.
- Synthetic license plates use realistic regional series (PB10, DL3C, CH01, HR26) on simulated vehicles.
